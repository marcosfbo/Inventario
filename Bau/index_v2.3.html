Informações de Armazenamento

Localização do Banco
Banco: SistemaInventario

O banco está armazenado localmente no seu navegador usando IndexedDB.

Possíveis localizações:
Chrome/Edge:
C:\Users\[Usuário]\AppData\Local\Google\Chrome\User Data\Default\IndexedDB\
Firefox:
C:\Users\[Usuário]\AppData\Roaming\Mozilla\Firefox\Profiles\[perfil]\storage\default\
Ferramentas do Desenvolvedor

Para inspecionar o banco de dados:

  1. Pressione F12
  2. Vá para a aba "Application" (Chrome) ou "Storage" (Firefox)
  3. No menu lateral: IndexedDB → SistemaInventario
  4. Você verá as tabelas: tbUnidades, tbEquipamentos, tbInventario
Importante - Dados Locais
Os dados ficam armazenados apenas neste navegador!

Se você:

  • Limpar os dados do navegador
  • Usar modo anônimo/privativo
  • Trocar de navegador ou computador
  • Atualizar/reinstalar o navegador

Os dados serão perdidos!

Recomendação

Faça backup regularmente usando a seção "Backup & Importação" para evitar perda de dados.
